# Security policy

## Supported versions

LangQuant is an alpha research prototype. Security fixes are applied to the
latest released version only.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting flow for this repository:

<https://github.com/hermes-labs-ai/langquant/security/advisories/new>

Do not include credentials, private transcripts, model outputs containing
sensitive data, or exploit details in a public issue. For ordinary bugs and
feature requests, use the public issue tracker.
